# Pugh, An Analysis of the Lanczos Gamma Approximation (2004)

## Why this source

The careful published error analysis of Spouge's approximation (within
a thesis primarily about Lanczos): section 3 derives the relative error
bound as a function of the parameter `a` that
`src/math/gamma_stirling.rs` cites for its conservative `a` selection.
Spouge's own bound statement is correct but terse; Pugh's analysis is
the worked justification.

## What it grounds

The error bound behind `spouge_a_for`'s safety margin in
`src/math/gamma_stirling.rs`.

## Alternatives

Spouge's original paper carries the bound (`spouge-1994.md`); Pugh is
cited in addition because the kernel's margin choice followed his
analysis.
