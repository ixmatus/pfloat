# IEEE Std 1788-2015

## Why this source

The interval arithmetic standard, named in tree only as the boundary
marker for future work: pfloat-ball v1.0 deliberately does not
implement the 1788 inf sup interval face (ADR-0076 records the typed
boundary decision). The entry exists so the boundary is a recorded
pointer rather than folklore.

## What it grounds

Nothing yet. When an inf sup face lands, this entry gains clause
consumers; until then the ball semantics trace to the Fundamental
Theorem of Interval Arithmetic as stated in `pfloat-ball/src/spec.rs`
and to Johansson's Arb design (`johansson-arb-2017.md`). Division of
labor with the sibling interval project (which targets 1788 conformance
directly) is recorded in the program tracker, not here.

## Alternatives

The free proxy literature: Pryce's papers on the 1788 design (the
motions and the decoration system) and Kulisch's computer arithmetic
monographs. Cite those for readers without IEEE access; neither is
load bearing for current code, so neither gets its own entry.
